# Ecys (`@Eccys`)

Systems tools, browser extensions, Linux/Wayland automation, and JVM storage engines.

## Featured Projects

- **[`raven-bplus-kv`](https://github.com/Eccys/raven-bplus-kv)** — Page-oriented B+Tree storage engine and key-value store in Java.
- **[`equicord-plugins`](https://github.com/Eccys/equicord-plugins)** — Custom TypeScript client plugins and UI utilities.
- **[`imake-web`](https://github.com/Eccys/imake-web)** — Browser-based X11 `Imakefile` preprocessor and `Makefile` generator with CI test suite.
- **[`input`](https://github.com/Eccys/input)** — Composable keyboard & pointer gesture recognizer library with multi-key sequence fallback.
- **[`chess-trainer`](https://github.com/Eccys/chess-trainer)** — Manifest V3 browser extension for scheduled board-flip and tactical chime intervals.
- **[`myst-vpn-firefox-port`](https://github.com/Eccys/myst-vpn-firefox-port)** — Firefox WebExtension port with IPv6 proxy endpoint normalization.
- **[`SATSuite`](https://github.com/Eccys/SATSuite)** — Practice portal browser extension with per-question answer reveal controls.
- **[`vocab-boost`](https://github.com/Eccys/vocab-boost)** & **[`vocab-web`](https://github.com/Eccys/vocab-web)** — Spaced-repetition vocabulary tools across Kotlin and TypeScript.
- **[`autotype-linux-wayland`](https://github.com/Eccys/autotype-linux-wayland)** & **[`Hyprland-Script`](https://github.com/Eccys/Hyprland-Script)** — Wayland input automation and Hyprland desktop scripts.
- **[`ecys.xyz`](https://github.com/Eccys/ecys.xyz)** — Personal web portal and edge worker APIs.
